### 🛠️ Üzerinde Çalıştığım Projeler

#### 📚 [sorutakip.online](https://sorutakip.online)
YKS'ye hazırlanan öğrenciler için performans takip platformu. Next.js + Vercel + Supabase üzerine kurulu, dershane ve kurs merkezlerine yönelik B2B genişleme hedefiyle geliştiriliyor.

#### 🏋️ SporTakip AI
WhatsApp üzerinden çalışan, yapay zeka destekli kişisel sağlık ve performans takip sistemi. Beslenme/makro takibi, antrenman, su ve takviye takibini kapsıyor.
- **Mimari:** WhatsApp Cloud API → n8n Cloud (orkestrasyon) → Supabase Edge Function (TypeScript, iş mantığı) → Supabase PostgreSQL (RLS)
- **Tasarım ilkesi:** "AI dili anlar, kod hesaplar" — kalori/makro hesaplamaları LLM'e değil, deterministik bir Nutrition Engine'e bırakılıyor
- **Stack:** n8n, Supabase, OpenAI API (yalnızca NLU), PostgreSQL trigram fuzzy arama
